# HEIB12 — Global PDF Form Editor

أداة ويب عملية وسريعة لتحرير وتعبئة نماذج وملفات PDF مباشرة من المتصفح دون الحاجة إلى تثبيت برامج ثقيلة أو إرسال ملفاتك إلى خوادم خارجية.

## Live Demo
جرّب الأداة مباشرة من هنا:
https://alfr33.github.io/heib12---Global-PDF-Form-Editor/

## Key Features
- تعبئة وتعديل حقول ونصوص نماذج PDF بسهولة وسرعة.
- العمل مباشرة داخل المتصفح مع الحفاظ على خصوصية المستندات.
- واجهة واضحة وخفيفة مناسبة للطلاب والموظفين وأصحاب الأعمال.
- إمكانية حفظ وتصدير الملف النهائي بعد التعديل بنقرة واحدة.

## Usage
1. افتح رابط التجربة المباشرة أعلاه.
2. اختر ملف PDF من جهازك.
3. أضف النصوص أو عبّئ الحقول المطلوبة، ثم احفظ النسخة المعدّلة على جهازك.
